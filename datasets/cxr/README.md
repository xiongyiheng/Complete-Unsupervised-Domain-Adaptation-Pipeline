# Chest X-Ray (CXR) Dataset Setup

This directory outlines the data sources, experimental setup, and preprocessing requirements for the multi-source Chest X-Ray (CXR) datasets used in our framework.

## 1. Data Acquisition & Experimental Setup

To evaluate domain adaptation across different demographic and clinical sources, we utilize four distinct Chest X-Ray datasets. The raw images can be downloaded from the following Kaggle links:

* **RSNA:** [RSNA Pneumonia Detection Challenge](https://www.kaggle.com/c/rsna-pneumonia-detection-challenge)
* **Child-Xray:** [Pediatric Pneumonia Chest X-ray](https://www.kaggle.com/datasets/andrewmvd/pediatric-pneumonia-chest-xray)
* **LDD:** [Lungs Disease Dataset](https://www.kaggle.com/datasets/omkarmanohardalvi/lungs-disease-dataset-4-types)
* **CRD:** [COVID-19 Radiography Database](https://www.kaggle.com/datasets/tawsifurrahman/covid19-radiography-database)

**Task Definition:**
We focus on the binary classification between **Pneumonia** from **Non-Pneumonia** cases.

## 2. Preprocessing Pipeline

To ensure consistency across the different data sources, we recommend applying the following preprocessing steps to the 2D X-ray images:

1. **Spatial Resizing:** Resize all images to a standard dimension of **224 × 224** pixels.
2. **Normalization:** Normalize the pixel intensity values to the range of **[0, 1]**.

## 3. Reproducibility

Because the datasets provide varying split structures, we handle the training and test splits source-by-source to ensure a fair evaluation:

* **RSNA:** The official Kaggle dataset only provides ground truth labels for its training set. Therefore, we utilize exclusively this labeled training set and apply a **5-fold cross-validation** scheme across it.
* **Child-Xray:** We follow the official training/test split.
* **LDD:** We combine its official `train` and `val` sets to form our comprehensive training set, while keeping its official `test` set as our hold-out test set.
* **CRD:** We apply a **5-fold cross-validation** scheme across the dataset.

The `.txt` files located in the `cv_splits/` directory contain IDs that were **generated by ourselves**. They are provided here for reference, allowing anyone who wants to ensure exact reproducibility to use the exact same training and test data splits that we used in our benchmark.
