# Chest CT Dataset Setup

This directory outlines the data sources, experimental setup, and preprocessing requirements for the Chest CT dataset used in our framework.

## 1. Data Acquisition & Experimental Setup

The raw Chest CT images can be downloaded from the COVIDx CT-3 dataset on Kaggle:
* **Download link:** [https://www.kaggle.com/datasets/hgunraj/covidxct](https://www.kaggle.com/datasets/hgunraj/covidxct)

**Task and Domain Definition:**
For our experiments, we consider a binary classification task: **COVID vs. Non-COVID**. 
To construct the Unsupervised Domain Adaptation (UDA) setting, we define the domains as follows:
* **Domain 1:** Data from the CNCB site.
* **Domain 2:** Data from all other sites combined.

*Note: This specific domain arrangement reflects our chosen experimental setup, but the framework can easily be adapted to other settings or domain definitions.*

## 2. Preprocessing Pipeline

The raw data downloaded from Kaggle consists of individual 2D image slices (`.png` files). To prepare the data for 3D network architectures, we follow the preprocessing methodology outlined in the [GIONet paper](https://www.sciencedirect.com/science/article/pii/S0010482523005784).

We recommend applying the following steps:
1. **Group by Scan:** Aggregate all 2D `.png` image slices that belong to the same scan into a single 3D volume.
2. **Volumetric Resizing:** Resize the aggregated 3D volume to a fixed dimension of **256 × 256 × 64** (Height × Width × Depth).

## 3. Reproducibility

The downloaded dataset contains official train, validation, and test splits. However, **we do not use the official splits**. When separating the data into the domains described above, the official splits do not provide sufficient source/target data for both the COVID and Non-COVID classes. 

Instead, we combined all available data and created a custom **five-fold cross-validation** scheme. 

The `.txt` files located in the `cv_splits/` directory contain IDs that were **generated by ourselves**. They are provided here for reference, allowing anyone who wants to ensure exact reproducibility to use the exact same training and test data splits that we used in our benchmark.
